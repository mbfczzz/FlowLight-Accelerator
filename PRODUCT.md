# Product

## Platform
web

## Stack
User approved Go control API and node agent, React/TypeScript administration, and C#/.NET WPF Windows client with a separate Windows Service. Independent repository and deployment.

## Users
Windows PC players of VALORANT and League of Legends, and operators configuring games, regions, nodes and network lines.

## Product Purpose
FlowLight Accelerator / 流光加速器 lets a player select a game, region and authorized line, then start and stop a real acceleration session. Operators publish independently versioned game profiles and lines.

## Capabilities and Constraints
Windows x64 first, one live session per device. MySQL authoritative state, Redis optional cache. SS2022 and Realm data plane; Mihomo TUN client adapter. Real nodes and regions are not supplied yet; unverified lines must never display as tested or ready. No claimed game compatibility until real testing.

## Brand Commitments
FlowLight Accelerator. Client interaction follows the supplied UU-like game library and one-click acceleration brief; no imitation of proprietary implementation or artwork.

## Product Principles
- Runtime state and probe evidence determine readiness.
- A lease controls real node authorization, not only UI visibility.
- Configuration publication preserves existing sessions.
- Failed starts release capacity and retain diagnostic events.

User confirmed visual direction: dark Windows client, light administration web. Game library and one-click acceleration for players; clear operational tables for administrators.
